## Контракт

### `CompactTocNode` обновление

```ts
export type CompactTocNode = {
  id: string;
  level: 1 | 2 | 3 | 4 | 5 | 6;
  title: string;
  line: number;
  line_end: number;
  section_lines: number;
  numbering?: string;
  is_likely_artifact?: true;
  artifact_reason?: string;
  has_children?: true;       // NEW: flag — node has children that were trimmed
  children?: CompactTocNode[];
};
```

### `compactTocNode` API

```ts
export function compactTocNode(
  node: TocNode,
  options?: { markHiddenChildren?: boolean }
): CompactTocNode;
```

- `markHiddenChildren=true`: если `node.children.length > 0` но в результате `children` опущен (потому что caller обрезал) — устанавливаем `has_children: true`. Default `false` (backward compat).

В реальности `compactTocNode` сам не обрезает — он только превращает рекурсивно. Tримминг происходит в caller. Так что `compactTocNode` нужно знать «обрезал ли caller детей». Лучше передавать через explicit flag в момент когда caller знает.

**Альтернативно** (более чистый дизайн): сделать `compactTocNodeAtDepth(node, maxDepth)` в `_compact.ts` который сам и режет, и помечает. Тогда `view_toc_response.ts` использует его, а `read_section_response.ts` использует `compactTocNode` для mini-TOC напрямую.

Идём по альтернативному пути — он чище. Добавляем helper:

```ts
export function compactTocNodeAtDepth(
  node: TocNode,
  remainingDepth: number   // 1 = только этот уровень, 2 = + 1 уровень детей, ...
): CompactTocNode;
```

Внутри: если `remainingDepth <= 1` — компактим без children, и если `node.children.length > 0` — set `has_children: true`. Иначе — рекурсивно `compactTocNodeAtDepth(child, remainingDepth - 1)` для каждого child.

`compactTocNode` остаётся как есть — полный рекурсивный compact без trim. Используется в `read_section.children`. Для read_section children mini-TOC мы хотим помечать grand-children: вызываем `compactTocNodeAtDepth(child, 1)` (только этот child, без своих детей, но с флагом если есть).

```ts
export function compactTocNodeAtDepth(
  node: TocNode,
  remainingDepth: number
): CompactTocNode {
  const compact: CompactTocNode = {
    id: node.id,
    level: node.level,
    title: node.title,
    line: node.line,
    line_end: node.line_end,
    section_lines: node.section_lines,
  };
  if (node.numbering !== null) compact.numbering = node.numbering;
  if (node.is_likely_artifact) {
    compact.is_likely_artifact = true;
    if (node.artifact_reason !== undefined) {
      compact.artifact_reason = node.artifact_reason;
    }
  }
  if (remainingDepth > 1 && node.children.length > 0) {
    compact.children = node.children.map((c) =>
      compactTocNodeAtDepth(c, remainingDepth - 1)
    );
  } else if (node.children.length > 0) {
    compact.has_children = true;
  }
  return compact;
}
```

  3. `compactTocNodeAtDepth(leaf-node, 1)` → no `has_children` field (no children to mark).
